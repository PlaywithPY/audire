# Images des produits

Placez ici les images des appareils auditifs affichés sur la page **Solutions auditives**.

## Format recommandé

- **Format** : JPG ou PNG
- **Dimensions** : 800×600 px minimum (ratio 4:3 ou 16:9)
- **Poids** : < 200 KB (optimisez les images avant upload)
- **Nom de fichier** : utilisez des noms clairs, en minuscules, avec tirets
  - ✅ `oticon-real.jpg`
  - ✅ `bernafon-alpha.png`
  - ❌ `IMG_2024.jpg`

## Utilisation dans l'éditeur

1. Uploadez votre image dans ce dossier `/images/produits/`
2. Allez dans l'éditeur → onglet **📦 Produits**
3. Modifiez le JSON et ajoutez le chemin de l'image :
   ```json
   "image": "/audire/images/produits/votre-image.jpg"
   ```
4. Sauvegardez
