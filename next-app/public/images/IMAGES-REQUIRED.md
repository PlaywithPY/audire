## Recommandations générales

- **Format**: JPG ou WebP pour une meilleure performance
- **Dimensions**: Au moins 800x600px (ratio 4:3)
- **Qualité**: Haute résolution, bien éclairées
- **Style**: Cohérent entre toutes les images (même traitement colorimétrique si possible)
- **Optimisation**: Compressez les images pour le web (max 200-300KB par image)

## Ajustement des positions

Après avoir uploadé les images, vous pouvez ajuster la position de chaque image (pour bien cadrer le visage ou l'élément important) via l'interface admin :
- Admin → Gestion des Cards → Ajuster les positions d'images
