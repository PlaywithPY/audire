📦 Gestion des produits

Cette section permet de gérer les appareils auditifs affichés sur la page Solutions auditives.
Pour ajouter des images de produits, placez vos fichiers dans /images/produits/.

Format JSON — Modifiez le contenu directement ici. Les images doivent être uploadées dans /images/produits/
💡 Guide rapide
Structure d'un produit : 
{
  "id": "oticon-real",
  "nom": "Oticon Real",
  "marque": "Oticon",
  "gamme": "Premium",
  "type": "Contour d'oreille",
  "image": "/audire/images/produits/oticon-real.jpg",
  "description": "Description courte...",
  "caracteristiques": [
    "Caractéristique 1",
    "Caractéristique 2"
  ],
  "prix": "2800€ - 3500€",
  "highlight": true
}
Pour ajouter une image :
  1. Placez votre image JPG/PNG dans /images/produits/
  2. Utilisez le chemin : /audire/images/produits/nom-fichier.jpg
